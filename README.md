# Prácticas de Computación Científica y Álgebra con Python 

¡Hola! En este repositorio organizo y documento los scripts desarrollados durante mis prácticas de programación orientada a las ciencias exactas y la resolución de problemas matemáticos. 

El objetivo de este espacio es consolidar el uso de librerías esenciales del ecosistema científico y de datos, aplicando lógica de programación avanzada y automatización de procesos.

## Se utilizan:
* **Python 3**
* **NumPy:** Para cálculo numérico avanzado, optimización mediante operaciones vectorizadas y álgebra lineal.
* **Matplotlib (pyplot):** Para la automatización de reportes gráficos y análisis visual de datos experimentales.

---

##  Estructura del Repositorio

Para mantener el código ordenado y escalable, el repositorio está estructurado en las siguientes subcarpetas especializadas:

### 1.  [algebra-lineal](./algebra-lineal)
Espacio dedicado al álgebra matricial computacional.
* **Contenido:** Operaciones con matrices multidimensionales, cálculo de determinantes e inversión de matrices utilizando el módulo `np.linalg`.

### 2.  [analisis-datos](./analisis-datos)
Procesamiento de información experimental y generación de reportes visuales.
* **Contenido:** Scripts de automatización para la lectura de archivos externos de datos estructurados (`.txt`) y generación de múltiples gráficos de dispersión independientes.

### 3.  [calculo-algoritmico](./calculo-algoritmico)
Resolución automatizada de ecuaciones y optimización de código.
* **Contenido:** Algoritmos lógicos para la resolución de funciones cuadráticas (Fórmula de Bhaskara) y ejemplos de operaciones vectorizadas masivas para optimizar el rendimiento sin usar bucles tradicionales.

### 4.  [radiacion-cuerpo-negro](./radiacion-cuerpo-negro)
Estudio del comportamiento del cuerpo negro y su radiación térmica (`p2.py`).
* **Contenido:** Automatización en el procesamiento de datos experimentales para el análisis termodinámico y de emisión. Incluye el cálculo de resistencias y variaciones de temperatura, transformaciones logarítmicas/lineales para el modelado de datos y la validación de la **Ley de Desplazamiento de Wien** mediante regresión por mínimos cuadrados.
